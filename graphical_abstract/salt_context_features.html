1 Number of Fragments
(n_frag)		 n_frag = number of “.”-separated fragments in the SMILES How many separate species the molecule is written as Separates salts, mixtures and hydrates from single neutral molecules.
Magnesium stearate
n_frag = 3

2 Metal Atom Count
(n_metal)		 Σ atoms with element in {Li, Na, Mg, Al, K, Ca, Ti, V, Cr, Mn, Fe, Co, Ni, Cu, Zn} Number of metal atoms Metal ions can catalyse oxidation, chelate APIs and form insoluble salts.
Mg Al silicate
n_metal = 2
Mg + Al

(has_counterion)		 1 if n_frag > 1, else 0 Whether the molecule is a salt / multi-component Salt form vs free form: phenytoin sodium = 1, phenytoin = 0.

Salt context: 8 values per molecule (API and excipient separately), computed with RDKit from the SMILES (src/features.py, salt_context) and fed into each molecule tower. Example values are the model's own output for these SMILES. Notes: water in a hydrate counts as a fragment (lactose monohydrate → has_counterion = 1); HCl salts written as “.Cl” are neutral fragments (metformin HCl → charge_total = 0).
